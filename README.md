### Production Reference — PlayerOne

**PlayerOne** is a 7-stage civic leadership and governance simulation platform built for [CARO](https://carononprofit.org) — a US 501(c)(3) nonprofit operating across Bangladesh.

| Layer | What's built |
|---|---|
| Auth | Google OAuth · SMS OTP · Email OTP · multi-role guards |
| Backend | Supabase (PostgreSQL + RLS + Edge Functions) · 33 tables |
| AI | Anthropic API scoring · 8 evaluation rubrics · Bangla/Banglish support |
| Frontend | 50+ HTML pages · bilingual UI · design system · admin dashboard |
| Data | Research export pipeline · Google Drive integration · GA4 analytics |

Live platform → [playerone.carononprofit.org](https://playerone.carononprofit.org)
